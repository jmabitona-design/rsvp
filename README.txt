JOSHUA & LEA - PLAIN HTML WEDDING INVITATION

1. Extract the entire ZIP. Keep the assets folder alongside index.html.
2. Double-click index.html to open the invitation in your browser. No Node.js, React, npm, or build step is required.
3. To activate RSVP, open config.js in a text editor and paste your Google Forms responder URL between the empty quotes for googleFormsUrl. Save and refresh.

Until you add a valid link, the page says RSVP will open soon. The site does not create a Google Form or save responses itself. Guests complete your form in a new tab.

Suggested form fields: Full name; Email; Attending (Yes/No); Number of invited guests including you; Guest names; Note to the couple.

Test the responder link in a signed-out browser before sharing. Responses and any linked Google Sheet are managed in your Google account.

Edit index.html for wording, styles.css for appearance, script.js for interactions, and assets/ for photos and fonts. Schedule and dress code are still provisional. Reference images are placeholders; replace with the couple's original photos. Fonts approximate the supplied image.

Upload the whole folder to any static web host to share publicly. This download is separate from the previously published React website; that site has not been changed.
