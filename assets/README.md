# Joshua & Lea — Our Story Reference Asset Pack

This folder contains the visual building blocks needed to reproduce the supplied
Our Story reference as a real responsive webpage rather than as one flattened image.

## Included
- Warm paper texture
- Top-left and bottom-right floral clusters
- Leaf sprigs and branches
- Filled and outline hearts
- Sparkle ornament
- Curved left/right vine connector SVGs
- Tape overlay
- Polaroid shadow helper
- Reference CSS variables and layout starter
- Placeholder locations for the five real story photos

## Important
The reference screenshot itself is not included as a website background. The design is
constructed from separate assets + HTML/CSS so photos, text, hover tilt, and responsive
mobile behavior remain editable.

## Suggested story photo names
story-01.webp
story-02.webp

Put the actual five photos in:
assets/story/photo/

## Fonts
The reference uses an elegant script for the title and an editorial serif for body copy.
This pack does not bundle commercial/proprietary font files. Put your licensed font files
in assets/story/fonts/ and update @font-face in your site's CSS.
